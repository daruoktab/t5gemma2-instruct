Temuan kunci untuk fine-tuning

User makin singkat seiring percakapan — dari rata-rata 22 kata di turn pertama jadi 11 kata di turn terakhir. Wajar, karena makin lama user makin pakai shorthand ("oke", "makasih", dll).
Asst konsisten ~34 kata per turn di sepanjang percakapan, kecuali turn terakhir yang lebih singkat (salam penutup). Bagus untuk konsistensi training.
78% percakapan di bawah 3k token — aman untuk dijadikan single training sequence di T5Gemma2 tanpa perlu truncation yang agresif.
30.4% percakapan tanpa task sama sekali — ini porsi "pure chat". Perlu dicek: apakah cukup untuk model belajar tidak memaksakan task ke percakapan biasa.
